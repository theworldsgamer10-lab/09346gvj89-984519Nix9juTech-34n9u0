Privacy Policy

This application is a personal automation tool that uploads video content to a

YouTube channel owned by the operator.

  • It does not collect, store, or process data about any third party.
  • The only account data it accesses is the operator's own YouTube channel,

through the YouTube Data API v3, using OAuth credentials the operator creates.

  • No analytics, no cookies, no tracking, no advertising.
  • Credentials are stored as encrypted GitHub Actions secrets and are never

logged or transmitted anywhere except to Google's OAuth and API endpoints.

  • To revoke access at any time:

https://myaccount.google.com/permissions

Contact: the repository owner, via their GitHub profile.
